# Copper Plus Cables Website

A static, responsive, and mobile-friendly single-page website for Copper Plus Cables. 

## Project Features
- Built with HTML5, CSS3, and Vanilla JavaScript.
- Fully responsive design (mobile, tablet, desktop).
- No external frameworks or backend required.
- Optimized for direct hosting on GitHub Pages.
- Smooth scroll, lightweight animations, and accessible semantic markup.

## Local Setup

You do not need a server or build process to view this site locally. 
Simply open `index.html` in any modern web browser.
